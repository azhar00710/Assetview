1. PLATFORM OVERVIEW
================================================================================

AKK4 is an unmanned wellhead platform with 3 producing wells (AF-4, AF-9, AF-10)
connected to a production manifold with pig launcher, exporting via 14" pipeline
to NKPP platform.

Wells:
  - AF-4  (Slot 2) - Original well, production via KW-2801 safety cabinet
  - AF-9  (Slot 2) - New well, production via KW-2801 safety cabinet
  - AF-10 (Slot 6) - New well, production via KW-2801 safety cabinet

================================================================================
2. SYSTEMS BREAKDOWN
================================================================================

SYSTEM 1: PRODUCTION (Sheets 001, 005, 006, 007)
  Primary Function: Well production, flow control, manifolding, export
  Components:
    - 3 wells with DHSV, SSV, WV, HCV (choke) valves each
    - Wellhead safety cabinet KW-2801 (shared, designed for 2+1 future)
    - Production manifold with test manifold capability
    - Pig launcher GP-2802 (350 barg design)
    - 14" export pipeline to NKPP platform
    - ESV-289950 (14" ESD valve on export riser)
    - N2 accumulator skid G-2803.B (for hydraulic control)

SYSTEM 2: CORROSION INHIBITOR (Sheet 002)
  Primary Function: Chemical injection for corrosion protection
  Components:
    - Package G-2802
    - Storage tank Q-2802 (1000mm OD, 3.5 barg, 55°C, 3 m³/hr)
    - 3x injection pumps P-2802.A/B/C (6.3 l/hr each, 97/350 barg)
    - Local control panel (new)
    - Injection to all 3 wells (A→AF-4, B→AF-9, C→AF-10)

SYSTEM 3: DECK DRAIN & DRY SERVICE WATER (Sheet 003)
  Primary Function: Platform drainage and service water
  Components:
    - Sump tank Q-2803 (2000x2000x1000mm, 4 m³, 1.0 barg)
    - 4 flame arrestors (FA-2803 to FA-2806)
    - Drain network across 4 deck levels (well, upper, mezzanine, cellar)
    - Dry service water hose connections (boat landing)
    - Overflow to sea

SYSTEM 4: METHANOL INJECTION (Sheet 004)
  Primary Function: Hydrate inhibition
  Components:
    - Package G-2801 (portable skid)
    - Storage tank Q-2801 (2000mm ID x 6000mm, 3.5 barg, 55°C)
    - N2 blanketing system
    - Injection to upstream of choke valves and flowlines
    - Hose connection for boat supply

7. SAFETY SYSTEM HIERARCHY
================================================================================

ESD-0: Platform total shutdown
  - ESV-289950 closes (14" export)
  - All wells shut in
  - Bypass available (V-28121, V-28122 - locked)

ESD-1: Well shutdown (per well)
  - DHSV closes (downhole)
  - SSV closes (surface)
  - WV closes (wing)
  - HCV closes (choke) - automatic

ESD-2: Process shutdown
  - Choke valve closes
  - Partial shutdown

Fire/Gas Detection:
  - Fire detection (288801.XA/XS)
  - Local gas detection (JCS-28710.1)
  - Fusible plugs on each well

Process Trips:
  - PSHH (Pressure Switch High High) - multiple locations
  - PSLL (Pressure Switch Low Low) - multiple locations
  - TSHH (Temperature Switch High High)
  - LALL/LSLL (Level Alarm/Switch Low Low) - on tanks
